# Перенос «Соберись!» с GitHub Pages на Firebase Hosting

## Цель
- Старый адрес до завершения проверки: https://faxbax-ctrl.github.io/abkhazia-checklist/
- Новый адрес: https://abkhazia-checklist.web.app/
- Firebase-проект и Firestore **не меняются**: `abkhazia-checklist`, документ `checklists/shared`.
- Другое приложение проекта — «Дом!» на `dom-zadachi.web.app` — не затрагивается.
- Репозиторий следует делать приватным **только после проверки** нового адреса.

## Публикация

На компьютере с Node.js, доступом к GitHub и правами на Firebase-проект:

1. Убедиться на старом адресе, что все офлайн-правки синхронизированы с облаком.
2. Склонировать/обновить репозиторий и открыть его корневую папку.
3. Авторизоваться в Firebase CLI: `npx -y firebase-tools@15 login`.
4. Запустить: `sh deploy.sh`.
5. Открыть https://abkhazia-checklist.web.app/ и проверить вход Google.

`deploy.sh` публикует только `index.html`, `sw.js`, `manifest.webmanifest` и три PNG-иконки.
Конфигурация `firebase.json` использует **именованный target** `soberis` для сайта
`abkhazia-checklist`. Скрипт использует `--only hosting:soberis` и не может по этой
команде затронуть сайт `dom-zadachi`, правила Firestore или базу данных.

## Проверки перед закрытием GitHub-репозитория

- В Authentication → Settings → Authorized domains должен быть разрешен `abkhazia-checklist.web.app` (добавить при отсутствии).
- Войти тем же Google-аккаунтом; увидеть все поездки и шаблоны.
- Добавить тестовую задачу на новом адресе и увидеть ее на другом устройстве;
  удалить тестовую задачу после проверки.
- Проверить автономный запуск и последующую синхронизацию.
- Переустановить ярлык PWA на iPhone с нового адреса (старый ярлык привязан
  к GitHub Pages). На новом домене авторизация и локальные кэши отдельные.
- Убедиться, что на старом домене нет несинхронизированных локальных изменений.
- Только после успешных проверок перевести `abkhazia-checklist` в Private.

## Важное
Не изменять Firestore Security Rules, `firebaseConfig` и модели данных ради
этого переноса: приложение использует тот же Firebase-проект.
Не помещать в GitHub ключи доступа Firebase CLI, сервисные аккаунты, приватные
JSON-файлы и резервные копии.
Новый домен не переносит автоматически localStorage и вход из браузера старого
домена; нужные данные должны быть синхронизированы в Firestore.
